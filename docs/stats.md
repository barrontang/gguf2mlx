## Where the dashboard went

A traffic dashboard used to be published at **`/gguf2mlx/stats/`**, built from
`docs/stats/index.html` and refreshed by a scheduled workflow. It is gone, and that
is deliberate: the dashboard is generated by
[`djdarcy/github-traffic-tracker`](https://github.com/djdarcy/github-traffic-tracker),
which is **GPL-3.0-or-later**, while `gguf2mlx` is **Apache-2.0**. Commit `aad64bf`
("Stage 0: slim README, split docs, move traffic tracking out") removed the
dashboard, its images, and the generating workflow so the two licences stay in
separate repositories.

The tracker now lives in its own repository:

**[`barrontang/gguf2mlx-traffic`](https://github.com/barrontang/gguf2mlx-traffic)**
— repository traffic tracking for `gguf2mlx` (GPL-3.0-or-later).

## Why this page exists

`/stats/` is a stable, published URL — it is referenced from badges and from
outside this site. Rather than let it 404, this page holds the address so the link
keeps resolving. The clone badge above is served from the tracker's live gist and
updates whenever the tracker runs.

!!! info "Nothing is being measured here"
    This page is a pointer, not a dashboard. It is part of the Apache-2.0
    documentation site and deliberately contains no tracker-generated content.
